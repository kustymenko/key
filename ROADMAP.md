# Дорожня карта

Кожен етап закінчується тим, що вчитель відкриває тренажер і перевіряє пункти «Готово, коли».
Claude Code позначає виконані пункти: [ ] → [x].

## Етап 0. Підготовка
- [ ] Створити проєкт Vite, налаштувати збірку в один файл, Vitest, Playwright
- [ ] Скрипти npm: dev, build, test, shots
- [ ] Збірка в `docs/index.html`, перевірити, що файл закомічено
- [ ] Пояснити вчителю, як увімкнути GitHub Pages (Settings → Pages → Branch: main, папка /docs)
- [ ] Дизайн-план за навичками frontend-design і kids-ux: палітра, кольори пальців,
      шрифт з кирилицею, ескізи головних екранів, образ персонажа
**Готово, коли:** вчитель погодив дизайн-план і відкрив демонстраційну сторінку за посиланням GitHub Pages.

## Етап 1. Клавіатура
- [ ] Розкладки ЙЦУКЕН і QWERTY, карта пальців
- [ ] Екранна клавіатура з кольорами пальців, схема долонь
- [ ] Підсвічування клавіші, яку натиснули на справжній клавіатурі
- [ ] Розпізнавання неправильної розкладки
**Готово, коли:** натискання на справжній клавіатурі видно на екранній, з правильним пальцем.

## Етап 2. Перший урок
- [ ] Екран вправи: текст завдання, курсор, підказка наступної клавіші і пальця
- [ ] М'яка реакція на помилки
- [ ] Урок 1 обох курсів (А О / F J) від знайомства до завершення
- [ ] Екран завершення з зірочками
**Готово, коли:** дитина проходить урок 1 від початку до кінця без допомоги.

## Етап 3. Курс і рівні
- [ ] Усі уроки за навичкою typing-pedagogy, генератор вправ
- [ ] Банки слів і речень за навичкою ukrainian-content
- [ ] Рівні «1–2 клас» і «3–4 клас», статистика для 3–4 класу
- [ ] Карта пригод з уроками
**Готово, коли:** тести генератора проходять; обидва рівні відчутно різні.

## Етап 4. Профілі і збереження
- [ ] Екран «Хто ти?» з картками, створення профілю
- [ ] Збереження прогресу після кожної вправи
- [ ] Екран «Мої досягнення», значки
- [ ] Видалення профілю / скидання прогресу з підтвердженням для дорослого
**Готово, коли:** після закриття і відкриття файлу прогрес кожної дитини на місці.

## Етап 5. Звук і персонаж
- [ ] Озвучка через Web Speech API з запасним варіантом без голосу
- [ ] Звукові ефекти через Web Audio API
- [ ] Персонаж-помічник з емоціями і фразами
- [ ] Перемикачі звуку й озвучки
**Готово, коли:** озвучка працює на шкільному ноутбуці або тихо вимикається.

## Етап 6. Міні-ігри
- [ ] «Кульки» (відкривається після 3-го уроку)
- [ ] «Падаючі літери» (після 6-го уроку)
- [ ] Адаптивна швидкість
**Готово, коли:** ігри використовують лише вивчені літери, без «програшу».

## Етап 7. Шліфування
- [ ] Перевірка всіх екранів за чек-листом kids-ux на 1366×768 і 1920×1080
- [ ] Пропозиція перерви, пауза на Esc
- [ ] Перевірка на шкільному ноутбуці з дітьми, виправлення за відгуками
- [ ] Коротка інструкція для вчителя (одна сторінка)
**Готово, коли:** діти користуються тренажером самостійно.

## Нотатки між сесіями
Claude Code записує сюди коротко: що зроблено в останній сесії, що лишилось недоробленим,
які рішення погодив вчитель. Нова сесія починає саме з цього розділу.
