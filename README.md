# Клавіатурка — стартовий набір для Claude Code у хмарі

Тренажер сліпого друку для учнів 1–4 класів. Ви працюєте з Claude Code у браузері
(claude.ai/code) або в мобільному застосунку Claude, нічого не встановлюючи на комп'ютер.

## Що всередині

| Файл | Навіщо |
|---|---|
| `CLAUDE.md` | Головні правила проєкту. Claude Code читає його на початку кожної сесії. |
| `ROADMAP.md` | План з 8 етапів і «Нотатки між сесіями» — пам'ять проєкту. |
| `START_PROMPT.md` | Перше повідомлення для Claude Code і запити для наступних етапів. |
| `.claude/skills/` | Три навички: дитячий інтерфейс, методика друку, вміст і озвучка. |

## Що потрібно

- Платна підписка Claude, яка включає Claude Code (Pro, Max або Team).
- Безкоштовний обліковий запис GitHub (github.com). Це «сховище» для файлів проєкту:
  хмарний Claude Code бере файли звідти й туди ж зберігає зміни.

## Підготовка (один раз, ~20 хвилин)

### 1. Створіть репозиторій на GitHub
Увійдіть на github.com → кнопка «New» (новий репозиторій) → назва, наприклад
`klaviaturka` → оберіть **Public** → «Create repository».

Чому Public: безкоштовна публікація сторінки (GitHub Pages) працює саме з публічними
репозиторіями. У проєкті немає нічого особистого: лише код тренажера. Дані дітей
зберігаються тільки в браузерах шкільних ноутбуків і на GitHub не потрапляють.

### 2. Завантажте файли набору
На сторінці нового репозиторію натисніть посилання «uploading an existing file»
і перетягніть у вікно ВЕСЬ вміст розпакованої папки `typing-trainer`
(включно з папкою `.claude`) → внизу «Commit changes».

Папка `.claude` починається з крапки. На Mac вона прихована: у Finder натисніть
Cmd+Shift+. (крапка), щоб її побачити. Після завантаження перевірте, що на GitHub
видно папку `.claude` — без неї навички не працюватимуть.

### 3. Підключіть GitHub до Claude Code
Відкрийте claude.ai/code → увійдіть → «Sign in with GitHub» і підтвердіть доступ.
Встановіть також Claude GitHub App на свій репозиторій, коли вам це запропонують
(або за посиланням github.com/apps/claude/installations/new): так Claude зможе
зберігати зміни саме у вашому репозиторії.

Середовище «Default» створиться автоматично, змінювати його не потрібно.

### 4. Увімкніть GitHub Pages (після першої сесії)
Коли Claude Code завершить Етап 0 і ви злиєте зміни (див. нижче), у репозиторії на GitHub:
Settings → Pages → Branch: **main**, папка **/docs** → Save.
Через 1–2 хвилини з'явиться посилання на кшталт `https://ваш-логін.github.io/klaviaturka/`.
Це і є ваш тренажер, який оновлюватиметься після кожного етапу.

## Як проходить кожен етап

1. Відкрийте claude.ai/code, оберіть свій репозиторій.
2. Режим (поруч із полем вводу): для Етапу 0 — **Plan** (Claude спершу покаже план
   і чекатиме згоди), для наступних — **Accept edits**.
3. Вставте запит із `START_PROMPT.md` і надішліть.
4. Чекайте. Сесія працює в хмарі, вкладку можна закрити, а прогрес дивитися
   з телефона в застосунку Claude.
5. Коли Claude закінчить, натисніть **Create PR**, потім на GitHub —
   **Merge pull request** → **Confirm merge**.
6. Відкрийте посилання GitHub Pages і перевірте тренажер (за 1–2 хв після злиття).
7. Зауваження пишіть у ту ж сесію, якщо вона ще відкрита, або в нову з наступним етапом.

## Як отримати тренажер для шкільних ноутбуків

- **З інтернетом:** просто відкривайте посилання GitHub Pages у Chrome.
- **Без інтернету:** на GitHub відкрийте файл `docs/index.html` → кнопка «Download raw file».
  Скопіюйте його на флешку й відкривайте подвійним кліком на кожному ноутбуці.

Прогрес дітей зберігається в браузері конкретного ноутбука і окремо для посилання
та для файлу. Оберіть один спосіб і не змінюйте його. Якщо почистити дані браузера,
прогрес зникне.

## Якщо щось пішло не так

- **Claude каже, що мережа блокує завантаження** (найімовірніше, браузера для знімків
  екрана): на claude.ai/code натисніть значок хмари з назвою середовища над полем вводу →
  шестерня біля «Default» → Network access: **Custom** → поставте позначку «Also include
  default list…» → додайте домен, який назвав Claude → збережіть.
- **Зміна не сподобалась:** напишіть «Поверни як було до останньої зміни».
- **Не бачу змін на сторінці:** перевірте, що pull request злито, і зачекайте 2 хвилини.
