# Клавіатурка — тренажер сліпого друку для 1–6 класів

## Про проєкт
Навчальний тренажер сліпого друку: «світ» для учнів початкової школи 1–4 класів (6–10 років) і окремий «світ» для 5–6 класів
(11–12 років) в тому самому файлі.
Працює на шкільних ноутбуках у браузері Chrome, часто БЕЗ інтернету.
За один ноутбук по черзі сідають діти різних класів.

Власниця/власник проєкту — вчитель, не програміст. Тому:
- Спілкуйся з користувачем УКРАЇНСЬКОЮ, простою мовою, без технічного жаргону.
- Ніколи не проси користувача самостійно редагувати код. Усі зміни роби сам.
- Після кожного етапу коротко поясни: що зроблено, як це перевірити, що далі.
- Перед великими змінами покажи план і дочекайся згоди.

## Обов'язкові вимоги (не порушувати)
1. Фінальний результат — ОДИН файл `docs/index.html`, який відкривається подвійним
   кліком без інтернету і без сервера. Усі шрифти, зображення, звуки — всередині файлу.
   Папка `docs/` КОМІТИТЬСЯ в репозиторій: з неї GitHub Pages показує тренажер вчителю.
2. Жодних мережевих запитів, аналітики, реклами, зовнішніх посилань.
3. Прогрес зберігається в localStorage, кожне звернення — в try/catch.
   Якщо сховище недоступне, тренажер працює далі (без збереження).
4. Інтерфейс повністю українською. Курси: українська (ЙЦУКЕН) і англійська (QWERTY).
5. Рівні складності: «1–2 клас», «3–4 клас» (дитячий світ) і «5 клас», «6 клас» (світ для 5–6 класів). Деталі в навичці typing-pedagogy.
6. Персонаж і всі зображення — власні, оригінальні. Жодних відомих персонажів,
   брендів чи схожих на них образів.
7. Нічого в частині для 1–4 класів не ламати. Після кожного етапу 5–6 класів проганяй `node scripts/stage4.mjs`, `node scripts/playall.mjs`
   і `npm test`: вони мають проходити без змін. Світ 5–6 класів додається поруч (`src/teen/`), а не переписує дитячий.
8. Стиль 5–6 класів — лише загальний жанр (кубічний/піксельний/low-poly світ, досвід, квести, аватар, колекції). Жодних логотипів, назв,
   персонажів, текстур, шрифтів, валют чи інтерфейсів відомих ігор (Minecraft, Roblox та подібних). Усе власне й оригінальне.
9. Тексти для вправ 5–6 класів — лише власні. Жодних уривків з книжок, пісень, віршів чи статей.
10. Змагання 5–6 класів: таблиця лише в межах ноутбука, спільна для всіх світів, увімкнена за замовчуванням, лише перша п'ятірка, ніколи
   останні місця, змагання з власним рекордом, вимикається в «Для дорослого». Обмін результатами — файлами (експорт/імпорт), без мережі.
11. Один код — три світи: логіку 5–6 класів пишемо один раз, світ лише міняє оформлення (теми в `src/teen/worlds/`). Кожен екран 5–6 має тест
   «відкривається в усіх трьох світах». Правило кольорів пальців діє в усіх трьох світах (особливо перевіряй клавіатуру на темному тлі «Небесних островів»).

## Функції (повний перелік; для 1–4 класів)
- Профілі дітей: картка з іменем і аватаром-тваринкою, без паролів.
- Екранна клавіатура з кольорами пальців, підсвічування наступної клавіші і пальця.
- Поступові уроки від основного ряду (ФІВА ОЛДЖ / ASDF JKL;).
- Вільне друкування слів і речень.
- Озвучка (Web Speech API) і звукові ефекти (Web Audio API, без аудіофайлів).
- Помилки: м'яка підказка для всіх + лічильник помилок, точність і швидкість для 3–4 класу.
- Ігрові елементи: персонаж-помічник, карта пригод, 1–3 зірочки за урок, значки,
  міні-ігри «Кульки» і «Падаючі літери», екран «Мої досягнення».
- Розпізнавання неправильної розкладки з підказкою «Перемкни мову: Alt+Shift».

## Світ 5–6 класів (окремий розділ плану в ROADMAP.md)
- Вибір класу при створенні профілю: 1–2, 3–4, 5, 6. 5 і 6 класи — окремі рівні (різні цілі й довжина текстів), спільний «дорослий» інтерфейс.
- Порядок створення профілю 5–6: ім'я → клас (5 або 6) → вибір СВОГО СВІТУ з трьох карток. Світ можна змінити будь-коли в налаштуваннях героя; прогрес
  при цьому зберігається (світ — лише тема оформлення).
- Вступний тест: визначає, хто друкує наосліп, а хто починає з нуля; відкриває відповідну частину курсу. Початківці йдуть швидшим темпом, ніж молодші.
- Довгі тексти й абзаци, усі розділові знаки, лапки, дужки, тире, апостроф, Ґ; цифри й символи верхнього ряду.
- Випробування на час: цілі швидкості й точності окремо для 5 і 6 класу (точність важливіша).
- Ігрова оболонка: досвід і рівні, квести, аватар, колекції нагород, світи для відкриття. Помічник свій у кожному світі (куб-бот, привид-спрайт,
  іскра): лаконічний, його можна сховати.
- Змагання: таблиця лідерів ноутбука (п'ятірка), особистий рекорд, вимикач; експорт результатів і імпорт на комп'ютері вчителя.
- Три світи (рішення вчителя: голосування скасовано, лишаються ВСІ ТРИ, кожен учень обирає свій): «Кубічний світ» (`voxel`), «Піксель-аркада» (`pixel`),
  «Небесні острови» (`sky`). Світ — ЛИШЕ тема оформлення: кольори, графіка, шрифти, карта, герой, помічник.
- Архітектура: уся логіка (уроки, тест, квести, досвід, нагороди, прогрес, таблиця лідерів, експорт) ОДНА для всіх світів. Кожну нову функцію пишемо
  один раз; вона працює в усіх трьох. Екрани 5–6 беруть малюнки й тему зі «світу» (`src/teen/worlds/<id>.js`), а не мають власної логіки.
  Тест: кожен екран 5–6 класів відкривається в кожному з трьох світів. Знімки перевіряй для всіх трьох.
- Демо-концепції (`src/concepts/`, `#concepts`, `#voxel`, `#pixel`, `#sky`) — джерело тем; після Етапу Т1 їхній код переїжджає в `src/teen/worlds/`.
  Посилань на концепції в екранах 1–4 не додавати.
- Правило кольорів пальців діє і тут: на екранах з клавіатурою оточення нейтральне, яскраві лише пальці.

## Технології
- Vite + чистий JavaScript (ES-модулі) + CSS. Без React/Vue — проєкт має лишатися простим.
- `vite-plugin-singlefile` для збирання в один HTML-файл.
- Шрифт з підтримкою кирилиці, підключений через пакет @fontsource і вбудований у збірку.
- Vitest — тести логіки (карта пальців, генерація вправ, підрахунок зірочок).
- Playwright — знімки екрана для самоперевірки інтерфейсу.

## Структура
```
src/
  main.js            — запуск, перемикання екранів
  screens/           — екрани: профілі, карта, урок, гра, досягнення
  keyboard/          — розкладки, карта пальців, екранна клавіатура
  lessons/           — опис уроків і генератор вправ
  games/             — міні-ігри
  audio/             — озвучка і звуки
  storage/           — профілі і прогрес (localStorage)
  content/           — банки слів і речень, фрази персонажа (лише дані)
  concepts/          — ДЕМО-концепції стилю 5–6 класів (тимчасово; після вибору стилю лишиться обраний)
  teen/              — (буде) 5–6 класи: logic/ (одна логіка), screens/ (екрани), worlds/ (три теми: voxel, pixel, sky), content/ (тексти)
  styles/            — CSS: токени дизайну, компоненти
tests/               — тести Vitest
screenshots/         — знімки Playwright (не комітити)
docs/                — зібраний тренажер для GitHub Pages (комітити!)
```

## Команди
- `npm run dev` — запуск для розробки
- `npm run build` — збірка `docs/index.html` (Vite: `build.outDir = 'docs'`)
- `npm test` — тести
- `npm run shots` — знімки екранів (1366×768 і 1920×1080)
- `node scripts/concepts.mjs` — знімки й перевірка демо-концепцій 5–6 класів (відкриваються, вправа проходиться, запитів немає)

## Робота в хмарі (Claude Code on the web)
Проєкт ведеться в хмарних сесіях Claude Code. Вчитель НЕ має локальної копії і НЕ бачить
твій сервер розробки. Тому:
- Вчитель бачить результат лише на GitHub Pages (папка `docs/` гілки main) після злиття змін.
  Наприкінці кожного етапу обов'язково виконай `npm run build` і закоміть оновлений `docs/`.
- Кожна сесія починається з чистої копії репозиторію. Твоя пам'ять між сесіями — це
  `ROADMAP.md` (позначки і розділ «Нотатки»). Наприкінці сесії онови його.
- Один етап = одна сесія = одна гілка. Наприкінці підготуй зміни до pull request
  і коротко опиши вчителю, що натиснути: «Create PR», потім на GitHub «Merge pull request».
- Якщо встановлення чогось блокує мережа (наприклад, браузер для Playwright),
  не обходь це хитрощами: точно назви вчителю домен, який треба дозволити в налаштуваннях
  середовища, а поки перевіряй інтерфейс без знімків.

## Як працювати
- Рухайся етапами за файлом `ROADMAP.md`. Не перескакуй етапи.
- Перед роботою над інтерфейсом читай навички frontend-design і kids-ux (1–4 класи) або teen-ux (5–6 класи; kids-ux для 5–6 не застосовується).
- Перед роботою над уроками, клавіатурою чи ігровою логікою — typing-pedagogy (розділ «5–6 класи» для світу 5–6).
- Перед роботою зі словами, реченнями, озвучкою, текстами інтерфейсу — ukrainian-content (теж є розділ «5–6 класи»).
- Перед уроками про апостроф і Ґ, тире, лапки, символи Shift+цифри: попроси вчителя перевірити розташування на шкільному ноутбуці. Не вгадуй.
- Після кожного етапу: `npm test`, `npm run build`, `npm run shots`, переглянь знімки
  і виправ те, що виглядає погано, ДО того як звітувати користувачу.
- Позначай виконані пункти в `ROADMAP.md`.
- Назви змінних і функцій — англійською, короткі коментарі — українською.
